# Tool Comparison Chart

This page is for quick reference. If you want the reasoning behind the choices, start with the [AI Tool Guide overview](./index.md).

:::note
This chart covers **types of tools and when to use them**. It doesn't list specific prices or version features — those change so fast that listing them would only mislead you.
Check the official websites before you use anything.
:::

---

## Chat assistants

| Tool | Best for | Personality | Watch out for |
| --- | --- | --- | --- |
| ChatGPT | General use, when you're not sure what to pick | Most features, most complete ecosystem | Lots of options; easy for beginners to get distracted |
| Claude | Long documents, writing, polishing | Clearly structured, natural writing | Fewer add-ons |
| Gemini | Heavy users of Google's apps | Deeply connected to Gmail / Docs | Mind the permissions on work accounts |
| Copilot | Companies using Microsoft 365 | Works right inside Office | Depends on your company's license |
| Perplexity | Looking things up, needing sources | Answers come with citations | You still need to click and check the citations |

## By task

| Task | Best type of tool | Why | Watch out for |
| --- | --- | --- | --- |
| Writing emails / copy | Chat assistant | Adjustable tone; you can give it examples | Double-check any facts |
| Polishing / rewriting | Chat assistant | Low risk, clear results | Don't let it erase your own voice |
| Summarizing long documents | Assistant that handles long documents | Reads the whole thing at once | Make sure no key sections were skipped |
| Finding the latest information | AI with web search | Sources you can trace | Always click the links |
| Organizing data / spreadsheets | Assistant that can run code | Actually calculates instead of guessing | Check the totals |
| Making a presentation | Assistant first, then a presentation tool | Handle content and layout separately | Generating it all at once tends to come out empty |
| Creating images | Image tool | High quality and control | Check the license for commercial use |
| Meeting notes | Transcription + assistant summary | Currently the most bang for your buck | Check policy first if it's confidential |
| Translation | DeepL or a chat assistant | Assistants let you set tone and context | Proofread names and specialized terms |
| Working with your own documents | AI knowledge base (e.g., NotebookLM) | Answers only from your material | Still check the cited passages |
| Building small tools / web pages | Vibe coding tools | Plain language is enough to build things | See [Vibe Coding](../vibe-coding/index.md) |

## Data sensitivity guide

Use this chart to decide "which kind of tool can I use for this?":

| Type of data | Personal free plan | Personal paid plan | Company-purchased business plan |
| --- | --- | --- | --- |
| Public information, practice material | OK | OK | OK |
| Personal drafts, study notes | OK | OK | OK |
| Internal, non-confidential company documents | Check company policy first | Check company policy first | Follow company rules |
| Client lists, quotes, contracts | Don't | Don't | Follow company rules |
| Personal, financial, or medical data | Don't | Don't | Needs legal/compliance sign-off |

For the full explanation, see [Safety & Judgment](../safety/index.md).

## A one-page decision checklist

1. Does this task need **up-to-date information**? → If yes, use a tool with search.
2. Does it need **precise calculations**? → If yes, use a tool that can run code, or double-check the math yourself.
3. Are **you providing the information**, or asking it to **recall it on its own**? → Provide the information whenever you can.
4. Does it involve **company or client data**? → If yes, check the policy first.
5. None of the above is an issue → Just use your main assistant.

:::tip
For 90% of everyday tasks, one main chat assistant is all you need.
Tool anxiety usually comes from not knowing your current tool well enough, not from the tool falling short.
:::
